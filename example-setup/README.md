# Example Setup

**This is not a template you're meant to fill in — it's a copy of my (greenpoison's) real Steam Deck modpack, kept here for reference.** If you want a working starting point that matches an actual, fairly large (200+ mod) install, point the mod at this profile and go from there.

## Where this data came from

This entries list was generated by scanning every mod's own `config.json` on my Steam Deck (SD-card-free install, at `~/.local/share/Steam/steamapps/common/Stardew Valley/Mods`) for fields that hold a valid SMAPI `SButton` keybind — either because the field name looks like a keybind setting (`...Key`, `...Button`, `...Bind`, `Controls.*`, etc.) or because the value itself parses as a real button combo. Content Patcher content packs (mods with no code, just data) were excluded, since they can't actually listen for a keypress. Out of 214 installed mod folders, 27 had real, code-backed keybinds — everything else was either a content pack or had no configurable keybind.

Each entry's `Name` and `Description` were written by hand afterwards, based on what the field name and the mod itself do — they're a best effort, not pulled from the mods' own documentation, so double-check anything that matters before relying on it.

## A conflict this scan actually found

**CapeStardewCode** binds `LeftShoulder + RightShoulder` to "Toggle Orb of Tides (Controller)" — which is the exact same combo this mod itself uses **by default** to open its own quick menu (`ModConfig.OpenMenuButton`). An earlier default of `LeftStick + RightStick` was tried specifically to dodge this, but that turned out worse - `RightStick` has a hardcoded vanilla behavior (opens chat/the emote wheel) that can't be suppressed at all, so the default reverted to `LeftShoulder + RightShoulder` despite this conflict, which is at least fixable. If you use this profile as-is, change `OpenMenuButton` in `config.json` to something else first (SMAPI's own `SuppressActiveKeybinds` stops it from also firing CapeStardewCode's action, but you'll still want a combo that isn't already spoken for). This is a good example of why the entries file is worth generating from your real setup rather than guessing — conflicts like this are easy to miss by hand across 27+ mods.

## Using this profile yourself

1. Copy the `profiles/SteamDeck` folder into your own mod's `data/profiles/` folder (so you'd end up with `data/profiles/SteamDeck/entries.json`).
2. Set `"ActiveProfile": "SteamDeck"` in your `config.json`.
3. Edit `entries.json` to match your own installed mods and their actual bound keys (check each mod's `config.json`, or its Generic Mod Config Menu page in-game) — this profile reflects my modpack, not necessarily yours, even if some mod names overlap.

The `presets/Farming Essentials.json` file shows what a preset looks like: a named subset of the entries above, switchable via `ActivePreset` in `config.json`.
